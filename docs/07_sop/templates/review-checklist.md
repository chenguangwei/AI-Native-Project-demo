# PR Review Checklist

## 基本信息

- 任务卡：
- PR 范围：
- 是否改契约：
- 是否改 DB：
- 是否改 CI/CD：
- 是否涉及权限、认证、支付、敏感数据：

## 正确性

- [ ] 验收标准全部满足。
- [ ] 成功路径和失败路径都有处理。
- [ ] 边界条件已覆盖。
- [ ] 并发、幂等、重复提交风险已考虑。

## 测试

- [ ] 有单元、集成、E2E 或合理替代验证。
- [ ] 测试断言行为，不只是跑通代码。
- [ ] 失败路径有测试。
- [ ] 测试数据可复现。

## 契约

- [ ] API、DB、事件字段与文档一致。
- [ ] 契约变化已走提案。
- [ ] 前后端 mock、类型、测试已同步。

## 安全

- [ ] 输入校验。
- [ ] 认证授权。
- [ ] 防注入。
- [ ] 敏感数据不落日志。
- [ ] 错误信息不泄露内部细节。

## 前端体验

- [ ] loading / empty / error 状态完整。
- [ ] 响应式布局可用。
- [ ] 基础可访问性可用。
- [ ] 文案清晰，没有调试文案。

## 运维

- [ ] 配置项有默认值或说明。
- [ ] 日志和监控可定位问题。
- [ ] migration 可回滚或风险已确认。
- [ ] 发布和回滚步骤清楚。

## 完成记录

```text
验证命令：

结果：

风险：

下一步：
```
